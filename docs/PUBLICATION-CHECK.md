# 发布检查范围

准备日期：2026-10-08。

此发布包通过明确文件清单生成，不从整个开发目录递归打包，也不复制任何原 Git 历史。只包含最新多账号应用、空数据库迁移、虚构测试、Node 部署适配与发布文档。具体文件和 SHA-256 记录在 release-manifest.json。

检查包含：发布树私密路径阻断、常见密钥模式、本机已有配置的密钥精确比对、原仓库 Git 对象检查、新发布 Git 索引/历史复核、源码引用与素材来源核对、空环境启动和自动化行为测试。工具不打印或记录密钥值。

原仓库包含本机数据与平台元数据，不能直接作为公开上传目录。旧原型的历史测试 URL 是人为构造的非法配置案例；本发布包不含该旧测试模块。当前多账号测试使用明确的测试密码；本机预览环境曾使用同一测试密码，生产环境不得使用它。

本发布不包含原有真实 API Key、数据库、订单备份、截图、日志、平台项目标识或站点地址。只有经人工查看的抽象背景图片进入发布包。

尚未验证：GitHub 远端 Actions、Docker/Linux 容器、真实模型的所有文本质量、服务器 HTTPS 与国内真实访问、正式支付/订阅。密钥模式与精确比对不能证明不存在所有类型的机密；本检查不等于渗透测试或完整法律审查。

应结合单独交付的准备报告查看本次实际测试结果，不把这份范围说明当作尚未执行检查的通过证明。
